## Contexto
Organizar `tests/robot` em Page Objects (uma classe por tela com elementos e ações) para manter e reaproveitar.

## Critérios de aceitação (BDD)
- **Dado** uma mudança no layout de uma tela, **quando** ajusto o Page Object dela, **então** nenhum cenário precisa mudar.
